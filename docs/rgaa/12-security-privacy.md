# 12 — Security and privacy

Rendered content is untrusted and cannot choose tests, origins, authority,
provider code or artifact policy. Native expressions are shipped constants;
the provider is a local hash-pinned bundle in a non-universal isolated world,
with no dynamic plugin or network load. Results omit provider HTML snippets
and bound strings/rules/nodes. Shared node and byte budgets cover text,
subtrees, sibling paths and label indexing rather than only the outer walker;
Chromium also receives an isolated execution timeout. Cleanup uses a short
independent budget but still verifies the assigned document and allowed origin.

Passive scans do not persist HTML or screenshots. Inline selectors, CSS
values and short accessible names remain page-derived and pass through the
normal redaction/output bounds. Future screenshots, documents or full DOM
must be `opaque-restricted`. Cross-origin frames never become implicit passes;
only top-level frame metadata is concluded where the official test permits.
