# 11 — Test strategy

Browser-free tests assert official hashes/cardinalities, complete joins,
deterministic generation, selection errors, verdict truth tables, provider
advisory isolation, sample budgets/digests, CLI output, and exact CDP methods.
The protocol mock proves that passive probes are fixed, focus uses trusted
Input events, spacing is privileged, and axe uses an isolated world.

Real Chromium runs accessible and controlled-regression fixtures. The full
`./dev check` additionally preserves Symfony, Shopware, packaging, docs,
coverage and proof gates. Catalog/provider changes must update pins and
negative tests; new rules require baseline, failure and ambiguous cases.
