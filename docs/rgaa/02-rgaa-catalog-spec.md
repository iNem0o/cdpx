# 02 — Catalog specification

`cdpx.rgaa.catalog/v1` represents one explicit `catalog_id` and
`rgaa_version`. It contains source provenance, 13 ordered themes, 106 criteria,
258 test records, official statements/methodologies, special cases,
references, and one automation profile per test.

The generator fails on an unpinned source, a hash mismatch, a duplicate or
orphan ID, a missing methodology/profile, or any cardinality other than
13/106/258. Generated bytes are deterministic. RGAA 5 must use a new catalog
ID beside 4.1.2; no code path means “current RGAA”.

Criteria and tests remain distinct. A WCAG rule, a provider rule, or a
criterion-level heuristic cannot silently create an official test verdict.
