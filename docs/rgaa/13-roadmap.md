# 13 — Roadmap

Completed foundations: official catalog, exhaustive matrix, verdict model,
fixed DOM/CSS collector, deterministic static rules, advisory axe provider,
trusted focus traversal, text-spacing emulation, declared samples, schemas,
fixtures, docs and proof registration.

Next increments must remain atomic: richer DOMSnapshot/AX evidence; more
official test families; screenshot-backed visual review; explicit multi-state
scenario links; a dedicated cockpit drill-down; optional document/AT harnesses;
and a parallel RGAA 5 catalog once published. Each increment adds mappings,
limitations, mock and real-runtime evidence before enabling automatic powers.
